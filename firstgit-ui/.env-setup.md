# FirstGit UI - Environment Files Guide

## Development Setup

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Create .env file** (optional, for non-standard backend URLs):
   ```bash
   cp .env.example .env.local
   ```

3. **Run development server**:
   ```bash
   npm run dev
   ```
   - Frontend: http://localhost:5173
   - Backend: http://localhost:8080 (via Vite proxy)
   - OAuth will redirect to http://localhost:8080

## Production Deployment on Netlify

### Environment Variables on Netlify Dashboard

1. Go to **Netlify Dashboard** → Your Site → **Settings** → **Build & Deploy** → **Environment**
2. Add these variables:
   ```
   VITE_API_URL = https://firstgit-api.onrender.com
   ```

### Automatic Deployment

1. Connect your GitHub repository to Netlify
2. Netlify will:
   - Detect `firstgit-ui` folder (via `netlify.toml` base directory)
   - Run `npm run build` automatically
   - Deploy to CDN

### API Proxy Configuration

The `netlify.toml` file is already configured to:
- Forward `/api/*` calls to the Render backend
- Forward `/oauth2/*` calls to the Render backend
- Handle SPA routing (404s redirect to index.html)

**No additional configuration needed!**

## Environment Variables Explained

### VITE_API_URL
- **Development**: Uses Vite proxy (configured in `vite.config.js`)
- **Production**: Points to Render backend
- **Default**: Empty string (uses relative URLs)

### IS_DEV Detection
The code automatically detects environment:
```javascript
const IS_DEV = !import.meta.env.PROD;
```
- Development: `npm run dev` → `IS_DEV = true`
- Production: `npm run build` → `IS_DEV = false`

## Troubleshooting

### Frontend can't reach backend
- **Check**: Netlify environment variables are set correctly
- **Check**: Backend (Render) is running and accessible
- **Check**: `netlify.toml` redirects are in place

### OAuth redirect fails
- **Cause**: OAuth callback URL mismatch
- **Fix**: Verify GitHub OAuth app callback URL matches Render URL
- **Fix**: Verify Render environment variable `FRONTEND_URL` is correct

### CORS errors
- **Cause**: Frontend trying to call backend directly
- **Fix**: Use Netlify redirects (already configured in `netlify.toml`)
- **Fix**: Ensure VITE_API_URL is set on Netlify

### Can't login after deployment
- **Check**: Backend deployed and running
- **Check**: GitHub OAuth app is configured with Render URL
- **Check**: JWT_SECRET is set on Render
- **Check**: Cookies are HttpOnly + Secure (check DevTools)

## Development vs Production

| Setting | Development | Production |
|---------|-------------|-----------|
| Backend URL | localhost:8080 | Render URL |
| Proxy | Vite proxy | Netlify redirects |
| HTTPS | No | Yes (enforced) |
| Cookies | Secure=false | Secure=true |
| Build | npm run dev | npm run build |
